Kazy Video Uploader

A personal tool that uploads videos to the developer's own YouTube channel.

What it does

  • Uploads finished video files to the developer's own YouTube channel using the YouTube Data API.
  • Sets the title, description, tags, thumbnail, and scheduled publish time of those videos.
  • Reads the channel's own upload list to avoid duplicate uploads and to find open publishing slots.

This application is used only by its developer for their own channel. It is not offered to the public.

このアプリについて

開発者本人の YouTube チャンネルに、自分で制作した動画をアップロードするための個人用ツールです。YouTube Data API を使い、動画のアップロード、タイトル・概要欄・タグ・サムネイルの設定、公開予約を行います。開発者本人のチャンネル以外では使用しません。
